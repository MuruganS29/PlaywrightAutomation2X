# PlaywrightAutomation2X

This repository contains automation scripts and examples using Playwright. It is organized into chapters and examples to help you learn and practice Playwright automation.

## Folder Structure

- **Chapter01_javascript/**: Contains JavaScript examples for Playwright basics.
  - `Basics_01.js`: A basic example script.
  - `Hotcode.js`: Another example script.

## Prerequisites

- Node.js installed on your system.
- Playwright installed as a dependency.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/MuruganS29/PlaywrightAutomation2X.git
   ```

2. Navigate to the project directory:
   ```bash
   cd PlaywrightAutomation2X
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run an example script:
   ```bash
   node Chapter01_javascript/Basics_01.js
   ```
